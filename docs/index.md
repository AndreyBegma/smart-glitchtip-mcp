# smart-glitchtip-mcp — corpus index

Read in this order:

1. `../AGENTS.md` — the rules never traded away.
2. `decisions.md` — what was decided, with rejected alternatives.
3. `architecture.md` — how the server is put together.
4. `roadmap.md` — the backlog, dependencies and review gates.
5. `specs/` — the specification of the PR in hand.
6. `open-questions.md` — what is undecided, and the default if nobody answers.

| Folder | Holds |
|---|---|
| `specs/` | `<TRACKING-ID>-slug.md`, written by `glitchtip-spec` |
| `feature-plans/` | plans for work that arrived without a spec |
| `bug-reports/` | `glitchtip-bug-report` output, indexed in `bug-reports/index.md` |
| `fixes/` | fix notes from `glitchtip-fixer`, indexed in `fixes/index.md` |
| `verifications/` | `glitchtip-fix-verifier` output, indexed in `verifications/index.md` |
| `reference/` | `glitchtip-openapi.json` — snapshot of the GlitchTip API schema |
